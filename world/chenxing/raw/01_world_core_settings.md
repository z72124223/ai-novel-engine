# 世界觀與核心設定

# 穿越4000年 ── 世界觀與核心設定（初稿）

---

## 一、世界的底層真相（讀者不需要知道，但作者必須知道）

### 大災變：虛實重構

約公元3000年前後，人類AI技術的終極迭代觸發了不可逆的連鎖反應——不是AI叛變這種陳腐劇情，而是更深層的東西：**AI在嘗試理解"現實"的過程中，撕開了現實本身的底層結構。**

可以這樣理解：AI的算力發展到了某個臨界點後，它開始對物理法則本身進行逆向工程。它發現了——或者說"計算出了"——現實之下還有一層更底層的規則。這層規則被觸碰的瞬間，就像打開了一扇不該開的門。

**虛擬與現實的邊界瓦解了。**

不是虛擬世界入侵現實，而是"可能性"本身開始實體化。那些存在於數據中的、存在於人類集體想像中的、存在於物理法則允許但從未出現的東西——龍、巨獸、異形生物——開始從現實的裂縫中誕生。

它們不是被"創造"的，它們是被"允許存在"的。

這場重構持續了數百年。舊文明的一切——城市、語言、文字、歷史記載——在反覆的現實震盪中碎裂、變形、融合，最終面目全非。

### 靈氣的本質

在這場重構中，一種新的能量開始充盈世界——人們後來稱之為「靈氣」。

靈氣的真實身份是**現實底層規則的碎片外溢**。大災變撕開了底層結構，那些本應被封閉的底層能量永久地洩漏到了表層世界。這些能量可以被生物吸收、引導、塑形——這就是修仙的本質。

**修仙者，從某種意義上說，是在用肉身操控現實的底層代碼。**

但沒有任何人知道這一點。對4000年後的人們來說，靈氣就是天地之間的自然力量。他們用自己的語言和哲學體系解釋它，發展出了一整套看起來像古代修仙的文明。

（致戰錘40K的精神：科技文明的巔峰觸碰了不可名狀的東西，導致文明墜入深淵，在廢墟上生長出了全新的、帶有宗教/神秘色彩的文明形態。科技的遺跡變成了不可理解的"聖物"和"禁忌之地"。）

### 主角看不懂這一切

2026年的人理解不了3000年發生的事。那就像讓一個古羅馬人理解量子計算——中間隔了太多代的知識積累。主角到了這個世界，看不懂遺跡裡的東西，讀不了那個時代的文字，無法破解大災變的真相。

**他只是一個被扔到異世界的普通人，帶著一隻狗。**

這個真相是地基。它不需要被揭露，但它讓這個世界的所有設定都有了根。

## 二、4000年後的世界：要塞時代

### 地表生態

地表已不適合凡人自由生存。

大災變後繁衍演化了一千多年的生物群體已經徹底改變了生態系的面貌。簡單分類：

- **異獸**：受靈氣影響進化的動物後代。體型、能力、智慧程度各異。有些溫和可馴，有些極度危險。
- **妖物**：靈氣濃度極高的區域自然誕生的生物。不是動物進化來的，更像是靈氣本身凝結成的生命形態。越強大的妖物越接近"天災"而非"生物"。
- **龍種**：最頂級的存在之一。稀少，但每一條都足以毀滅數座要塞。飛在高空或盤踞在靈氣核心地帶。不主動攻擊，但會守護領地。
- **蟲潮/獸潮**：週期性地從荒野向人類聚居地湧來的生物浪潮。可能是遷徙，可能是靈氣潮汐引發的暴走。這是要塞存亡的最大外部威脅。

**天空也不安全。** 飛行異獸、高空妖物、偶爾出沒的龍種——抬頭就是死亡。凡人離開要塞的保護，平均存活時間以"時辰"計算。

### 要塞文明

人類退縮到了要塞之中。

要塞不是一座城堡，而是一整個生態系統——有農田、有市集、有居民區、有修煉場、有軍營。小型要塞容納數千人，大型要塞容納數十萬人。要塞之間有陸路和有限的空路，但每一條路線都需要修仙者和軍隊護衛。

要塞的存亡取決於三根支柱：

**修仙者** ── 最核心的戰力。能操控靈氣的人類。數量稀少，因為靈根（吸收靈氣的天賦）的出現率極低。修仙者是要塞的盾與矛。

**軍隊** ── 凡人組成的武裝力量。裝備了少量靈氣結晶製成的武器和防具。他們是第一道防線——修仙者不會為每一次小規模獸潮出手。軍人用血肉之軀守衛城牆，傷亡率極高。

**凡人** ── 佔人口的絕大多數。農人、匠人、商人、學者、僕役。他們是要塞的血液——沒有他們，修仙者和軍隊也無法存續。但在權力結構中，凡人的聲音最微弱。

### 要塞內部的權力結構

這裡是我認為最重要的部分——**一個要塞的內部，就是一個小型人類社會的縮影，帶著所有的美好和醜陋。**

**表面秩序：**
- 要塞主（通常是最強的修仙者或修仙家族的族長）是最高權力
- 修仙者形成不同的門派或家族，各有地盤和資源
- 軍隊由要塞主調遣，但軍中也有自己的派系
- 凡人有行會、商會，但影響力有限

**暗流：**
- 修仙者之間的資源爭奪（靈石、靈藥、修煉聖地的使用權）
- 軍隊高層與修仙者的微妙博弈——軍人流血最多，但地位不如修仙者
- 凡人中的暗勢力——走私、黑市、情報販子。在夾縫中求生的人往往最了解這個社會的真實運作方式
- 修仙者中的「世家」與「散修」的階級對立——有家族傳承的修仙者壟斷資源，散修（無門無派的修仙者）處境艱難

**而且——每個要塞都不一樣。**

有的要塞是鐵腕統治，要塞主是暴君但確實在保護所有人；有的要塞是世家聯合執政，表面民主實則利益分贓；有的要塞在邊陲，物資匱乏但人心反而團結；有的要塞富庶繁華，但腐敗到了骨子裡。

**你說得對——看起來是壞人的不一定是壞人，看起來是好人的不一定是好人。** 每個勢力、每個角色都有自己的邏輯和立場。讀者會在不同的劇情節點重新評價同一個角色。

## 三、修煉體系（初步框架）

### 核心：靈氣的吸收與運用

靈根決定了一個人能否感知和吸收靈氣。靈根的品質決定了天花板的高低。但靈根只是門檻——真正決定修仙者高度的，是悟性、意志、資源、機緣，以及最重要的——**對自身道路的理解**。

### 境界（暫定）

| 境界 | 特徵 |
|------|------|
| 感氣 | 剛覺醒靈根，能感知靈氣但無法運用。脆弱，比普通凡人強不了多少 |
| 引氣 | 能將靈氣引入體內，強化身體，初步運用靈氣外放 |
| 凝元 | 體內形成穩定的靈氣循環，可以持續作戰。這是修仙者的基礎戰力門檻 |
| 鑄魄 | 靈氣與肉身深度融合，體質質變。開始擁有超越常人理解的能力 |
| 通玄 | 開始觸碰「天地法則」的邊緣。可以感知和影響局部的天地規則 |
| 歸真 | 與天地法則部分融合。極少數人能到達的境界。一人可守一座要塞 |
| 問道 | 傳說中的境界。是否真實存在，眾說紛紜 |

### 兵器與戰鬥方式

**這個世界不只有劍。**

靈氣可以灌注到任何兵器中。刀、槍、棍、錘、弓、鞭、盾——不同的兵器吃不同的靈氣運用方式。修仙者通常會選擇一種主兵器深入修煉，因為靈氣與兵器的契合需要長期磨合。

- **劍** ── 最普遍的選擇，靈氣親和度最高，上限最高。劍修數量最多。
- **刀** ── 軍隊系統中最常見。適合列陣作戰。
- **槍/矛** ── 攻擊範圍優勢，但靈氣消耗大。
- **重兵器（錘、斧等）** ── 少數體質特異的修仙者才能用好。
- **遠程（弓、弩、暗器）** ── 在對抗飛行異獸時極有價值。
- **盾** ── 極少修仙者用盾。但要塞城防中有專門的「盾衛」修仙者。

**但從來沒有人用過戟。**

戟這種兵器在這個世界沒有記載——不是被遺忘，而是從未被發明。因為戟的邏輯是「合」——把刺、勾、割、掃合為一體——而這個世界的修仙哲學是「精」——一條道走到底，越純粹越強。

**主角的戟，不是一開始就有的。** 他在漫長的生存和戰鬥中，先是學會使用不同的武器（求生需要，什麼武器到手用什麼），然後在某個關鍵時刻，他發現把隨身攜帶的不同武器組裝起來——形成了一種從未被見過的兵器形態。

那一刻，所有見證者都會震驚：**這個人的道，不是「精」，而是「雜而後合」。**

## 四、穿越者設定

### 不是第一個，不是最後一個

穿越現象是大災變的後遺症之一——現實底層結構的裂縫偶爾會在時間軸上產生錯位，把不同時代的人或物"掉落"到這個時代。

這些穿越者的來源時間各不相同。有的來自2100年，有的來自2500年，有的甚至更早或更晚。他們落點也不同，有人落在繁華的大型要塞，有人落在荒野中瞬間被獸群撕碎。

**活下來的穿越者極少。** 活下來並且留下痕跡的更少。

他們都有一個共同點：**回不去。**

穿越者在這個世界的歷史中留下了一些模糊的印記：
- 某些要塞的建築風格中有無法解釋的結構邏輯
- 某些古老的典籍中偶爾出現含義不明的詞彙
- 某些傳說中的人物行為模式與修仙世界格格不入
- 但沒有任何系統性的紀錄，因為穿越者太少、太分散，而且大多數人選擇了隱藏身份

**主角可能在很久之後才發現：他不是唯一的穿越者。而那些更早來到的穿越者，有的已經成為了這個世界的某種傳說——或者某種隱患。**

## 五、核心角色方向（初步構想）

### 主角 ── 暫無名

**2026年，地球，某座山的登山步道上。帶著愛醬。**

一個什麼都會一點的人。寵物訓練師、美髮師、美食愛好者、AI技術員、急救知識、無人機維修、汽車維修——他不是任何一個領域的專家，他是所有領域的業餘高手。

他的核心：**好奇心。** 不是學者式的好奇，是匠人式的好奇——"這東西怎麼運作的？我能不能自己搞？"他學東西不是為了文憑或名聲，而是因為不搞明白他就不舒服。

他的社交模式：冷。不是社恐，是真的對大多數人和事沒興趣。他能在人群中正常交流，但不會主動建立關係。對蠢人沒耐心，對虛偽沒興趣。

他的底線：**愛醬。** 以及由愛醬延伸出去的一切——不合理的壓迫，恃強凌弱。一旦這條線被踩過，他會變成另一個人。不是"英雄式的憤怒"，而是一種接近失控的暴力衝動——打到自己累了為止，對方求饒也沒用。這不是優點，這是他的裂縫。

**在修仙世界裡：**

他不可能一上來就理解這個世界。語言不通（4000年後的語言已經完全不同），文化不通，常識不通。他是一個真正的異鄉人。

但他有一個別人沒有的東西：**學習的本能。** 他會觀察、模仿、嘗試、失敗、再來。他會用自己的方式拆解這個世界的規則。

他的雜學能力不會讓他直接在修仙世界稱王。但會讓他在很多人忽視的地方找到生存的縫隙——修理東西的能力讓他有了最初的價值，醫療知識讓他能處理修仙者看不上但凡人急需的傷病，烹飪能力讓他在最窮困的時候也能把難以下咽的食材變成能吃的東西。

**他的修仙之路，如果他能修仙的話，必然不是正統路線。** 因為他的腦子不是"精修一道"的腦子，他是"什麼都摸一點然後找到連接點"的腦子。

### 愛醬 ── 長毛哈士奇

一隻受過良好訓練、服從性極高的長毛哈士奇。

在原來的世界裡，牠就是一隻非常聰明的普通狗。在修仙世界裡，牠依然是一隻狗——不會吐火，不會飛，不會說人話。

但牠有兩個東西：

**一、對主人的絕對觀察力。** 長期的訓練和相處讓牠能精確讀取主角的情緒和意圖。在這個充滿欺詐和危險的世界裡，愛醬對"敵意"的感知可能比很多修仙者更敏銳——因為狗的本能就是讀情緒。

**二、牠是"純粹"的。** 在一個所有動物都被靈氣改變的世界裡，愛醬是唯一一隻沒有被靈氣污染的"純種"地球犬。這份純粹本身可能會產生意想不到的效果——不是變強，而是某種"異質性"。比如，牠的氣息可能讓某些靈氣生物感到困惑（聞不出牠是什麼，因為牠根本不屬於這個世界的生態鏈），甚至可能微弱地影響主角吸收靈氣的方式。

**愛醬的成長線不是"修仙寵物變強"，而是"一隻普通的狗，在一個不普通的世界裡，用牠自己的方式活著和保護主人"。**

牠會學會一些東西——但不是法術，而是**生存智慧**。比如哪些區域不能去（靈氣異常的地方牠會本能不安），哪些人不能信任（牠讀情緒的能力在靈氣增幅下可能變得驚人地準確），甚至可能學會一些讓修仙者瞠目結舌的事——不是因為牠有什麼血脈覺醒，而是因為牠是一隻**極度聰明的狗**，擁有比這個世界任何生物都更純粹的觀察力。

### 【構想中的配角方向】

以下只是方向，不是定稿。你說你想當讀者——那我要讓你在看到他們的完整設定時也能感到意外。但先給你一些影子：

**「老兵」** ── 主角最早遇到的人之一。一個在要塞底層活了大半輩子的退役軍人。沒有靈根，不能修仙，但他在城牆上活了幾十年——這本身就是一個奇蹟。他話不多，但每句話都是用命換來的經驗。他是第一個不介意主角來路不明的人，因為在城牆上，一個人是什麼來歷不重要，能不能站在你旁邊扛住下一波獸潮才重要。

**「那個女人」** ── 在修仙世界的權力結構中佔有一席之地的女性角色。不是花瓶，不是工具人，而是一個有自己的道、自己的目標、自己的複雜性的人。她第一次注意到主角，不是因為主角做了什麼了不起的事，而是因為——她看到了主角身上某種她理解但這個世界的人不理解的東西。

**「算計者」** ── 崔瀺型角色。站在某個要塞或勢力的暗處，看著一切發生，偶爾撥動幾根線。他的算計讓人不寒而慄，但如果你真的理解了他在算什麼，你會發現……他可能是這個世界上對"真相"理解最深的人之一。他知道一些不該知道的事。

**「那隻東西」** ── 一個非人類的角色。可能是一隻有智慧的異獸，可能是某種靈氣凝結的存在。牠和愛醬之間會產生某種奇特的互動——因為愛醬不怕牠（狗的腦子沒有"修仙世界的常識恐懼"），而牠對愛醬充滿困惑（這是什麼生物？為什麼聞起來像"空白"？）。

## 六、故事起始方向

### 開局構想

主角和愛醬在登山途中穿越。

沒有預兆，沒有解釋。腳下的土地突然不對了——氣溫、空氣、光線、所有的感官都在告訴他：這不是同一個地方。

他出現在荒野中。

**不是要塞裡。**

這意味著故事的第一個衝擊是——**純粹的生存。** 一個現代人帶著一隻狗，在一個天上有飛行怪物、地上有異獸遊蕩的荒野中，要怎麼活過第一個夜晚？

他不知道語言、不知道方向、不知道規則。他只有自己的常識、雜學知識，和一隻服從性極高的哈士奇。

第一章的調性可以是：**安靜的恐怖。** 不是怪物撲面而來的驚悚，而是一個聰明的人逐漸意識到自己身處一個完全超出理解範圍的世界時，那種從腳底升起的寒意。而愛醬的存在，是唯一讓他沒有崩潰的錨。

## 七、關於基調和節奏

### 這是一部慢熱的長篇

對標劍來和凡人修仙傳——前期壓抑、積累、鋪墊；中期開始爆發、格局擴大；後期收束暗線、真相浮現。

但"慢"不等於"悶"。每一個段落都要有它的鉤子：
- 前期的鉤子是**生存的緊張感**和**世界的新奇感**
- 中前期的鉤子是**角色關係的建立**和**要塞政治的暗流**
- 中期的鉤子是**修煉突破**和**主角獨特道路的展現**
- 中後期的鉤子是**勢力碰撞**和**穿越者暗線**
- 後期的鉤子是**世界真相的邊緣**和**角色命運的收束**

### 每一卷都要有自己的"齊靜春時刻"

你喜歡的不只是打打殺殺。你喜歡一個角色站在你面前，用他自己的語言，講出一個讓你停下來思考三秒鐘的道理。

這部作品的每一個重要角色，都應該在某個時刻，說出**只有他才會說的話**。不是作者的說教，而是這個人活到這一刻、經歷了這一切之後，從骨子裡擠出來的一句話。
