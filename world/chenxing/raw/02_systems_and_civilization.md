# 穿越4000年 ── 第二層設定：系統與文明

---

## 一、武器系統

### 武器分級

這個世界的武器不只是一根鐵棍或一把鋼劍。靈氣的存在讓武器有了「品質」的概念。

| 等級 | 說明 |
|------|------|
| **凡鐵** | 普通金屬打造，不含靈氣。凡人士兵的標配。可以殺異獸幼體，但對成年異獸幾乎無效。 |
| **靈鍛** | 鍛造時注入靈氣，金屬結構被改變。更硬、更輕、更鋒利，可以引導使用者的靈氣。引氣境以上的修仙者基本裝備。 |
| **器胎** | 以特殊的靈性礦石為主材鍛造，武器本身開始具備微弱的「性格」——對某些靈氣屬性更親和，對某些使用者更順手。凝元境修仙者追求的裝備。 |
| **道器** | 武器中開始生長出「器靈」的萌芽。不是真正的意識，更像是一種本能。道器與主人之間會形成共鳴——用得越久，越合手，甚至能在戰鬥中自發地做出微弱的配合反應。鑄魄境以上才能馭使。 |
| **靈寶** | 器靈完全覺醒。武器有了自己的意志（雖然簡單）。靈寶會挑主人——氣場不合的人根本拿不起來，或者拿起來反而被靈寶的意志壓制。通玄境級別的修仙者才配持有。 |
| **天器** | 傳說級。每一件天器的誕生都伴隨著異象，它們本身就像一個小型的「法則容器」——持有天器的人等於多了一條觸碰天地法則的通道。歸真境以上的頂尖強者才可能擁有。已知存世的天器不超過兩掌之數。 |
| **？？？** | 比天器更高的等級是否存在，沒有任何確認。但某些極古老的禁地遺跡中，偶爾會傳出讓歸真境修仙者都不敢靠近的兵器氣息。 |

### 武器類型（全面展開）

修仙世界的兵器種類遠比初稿豐富。靈氣可以灌注到幾乎任何形態的武器中，但不同形態與靈氣的契合方式不同，由此衍生出完全不同的戰鬥流派。

**近戰類：**
- **劍** ── 靈氣親和度最高，變化最多。飛劍術是劍修的標誌性能力。劍修數量最多，競爭也最激烈。
- **刀** ── 軍隊制式武器的首選。靈氣灌注後斬擊力驚人，適合正面戰場。刀修講究「勢」——一刀比一刀猛，層層疊加。
- **槍/矛** ── 攻擊距離優勢。槍修的靈氣運用方式偏「線性穿透」——將所有靈氣壓縮成一條直線，追求極致的破甲能力。
- **棍** ── 看似平凡，但棍修的靈氣運用反而最靈活——因為棍沒有刃，靈氣可以從任何一個點外放。棍修罕見，但往往是最難纏的對手。
- **錘/斧/重武器** ── 需要極強的體質。靈氣運用方式偏「爆發」——不追求持續輸出，而是把所有靈氣壓縮進一擊。一擊不中，間隙極大；一擊命中，天崩地裂。
- **雙兵（雙刀、雙劍、雙鉤等）** ── 靈氣分流運用，對控制力要求極高。雙兵修者少，但戰鬥觀賞性極強。
- **軟兵器（鞭、鎖鏈、繩鏢、流星錘）** ── 靈氣沿不規則軌跡運行，極難預判。使用者需要對靈氣的「流動」有天然的感知力。很多軟兵器使用者出身散修或非正統門派。
- **短兵（匕首、短刃、爪刃）** ── 近身格鬥專用。靈氣運用方式偏「滲透」——不是從外部劈砍，而是將靈氣灌入對手體內。暗殺者最愛。
- **盾** ── 極少數修仙者以盾為主兵器。靈氣運用方式偏「拒止」——形成靈氣壁壘。在要塞城防中有專門的「盾衛」序列，但在修仙者圈子裡，用盾被認為「不夠進取」。然而，能把盾用到極致的人，攻防轉換之間的爆發力會讓所有人意外。

**遠程類：**
- **弓** ── 將靈氣壓縮成箭矢形態射出。頂級弓修的一箭可以跨越數里擊殺飛行異獸。在要塞防空體系中地位極高。
- **弩/機關弩** ── 凡人軍隊的重要遠程武器。不需要靈根也能使用的「靈鍛弩」是要塞軍工的重要產品。
- **暗器（飛針、飛刃、毒蒺藜等）** ── 靈氣附著在細小物體上，追求意想不到的角度。暗器修者往往同時精通毒術或幻術。

**特殊類：**
- **符兵** ── 以符籙為「彈藥」的戰鬥方式。符師是一個獨立的修煉方向（見功法系統）。
- **傀儡/機關獸** ── 以靈氣驅動的機關造物。操控者本身可能戰鬥力不強，但他的傀儡可以替他衝鋒。製造傀儡需要極高的鍛造和符籙知識——**這是一個主角的雜學能力可能會在未來觸及的方向。**
- **樂器類（琴、笛、簫、鼓）** ── 以聲音為媒介運用靈氣。不是直接的物理傷害，而是影響對手的神識、情緒、甚至靈氣運行。極罕見，但遇到了極其棘手。
- **拳/體術** ── 不持兵器，以自身肉體為武器。靈氣全部灌注於體內。體修是一條苦行的路——前期弱於同級持兵器者，但一旦突破到鑄魄境以上，體修的肉身強度會讓其他修仙者絕望。

### 戟——不存在的兵器

**這個世界從未出現過戟。**

原因在於修仙哲學的底層邏輯：**「道貴精純」**。一個修仙者窮盡一生精力去深挖一種兵器形態，已經是極限。把兩種甚至三種兵器形態合而為一？這在理論上就是靈氣運用的自殺——你的靈氣無法同時適配刺、勾、割三種截然不同的力學邏輯。

但主角不是這個世界的人。他的腦子裡沒有「道貴精純」這四個字。他的本能是：**什麼都學一點，然後找到它們之間的連接。**

當他在某個緊急時刻，把手裡的短矛和腰間的鉤刀臨場組裝成一種所有人都沒見過的兵器形態時——

那一刻，在場的修仙者會看到一個他們的哲學體系完全無法解釋的東西：**一個人同時運行三種相互矛盾的靈氣軌跡，而且它們彼此沒有打架，反而形成了一個古怪但有效的循環。**

他們不會理解這是怎麼做到的。因為他們不知道，這個人的腦子從一開始就不是「專精」的結構——**他是一個天生的「整合者」，把不同的碎片拼成別人從未見過的整體。**

這就是「戟」在這個世界的意義：它不只是一種武器，**它是對這個世界修仙哲學的一次挑釁。**

## 二、功法系統

### 功法的本質

功法是修仙者吸收靈氣、運轉靈氣、運用靈氣的「路徑圖」。如果把人體比作一套水管系統，功法就是決定水從哪裡進、怎麼流、從哪裡出的設計圖。

不同的功法決定了：
- 靈氣吸收的速度和純度
- 體內靈氣流轉的路徑
- 靈氣外放的方式和屬性
- 修煉的上限（某些低級功法天花板就是凝元境，修到死也上不去）

### 功法分類

**按來源分：**

| 類型 | 說明 |
|------|------|
| **宗門正典** | 大宗門的核心功法。經過數百年甚至上千年的完善和修正，體系完整、路徑清晰、風險可控。但通常只傳給嫡系弟子。 |
| **家族秘傳** | 修仙世家代代相傳的功法。有的品質極高，有的已經在傳承中失真走樣。世家的核心競爭力之一。 |
| **散修自悟** | 散修靠機緣得到的殘篇，或者自己摸索出來的功法。品質參差不齊，有些天才散修自創的功法甚至能媲美宗門正典，但更多的散修因為功法有缺陷而走火入魔。 |
| **軍方功法** | 要塞軍隊為有靈根的士兵準備的制式功法。上限不高（通常到凝元境就是極限），但勝在穩定、安全、容易標準化教學。軍隊不需要天才，需要的是批量生產的穩定戰力。 |
| **禁功** | 被主流修仙界禁止的功法。原因各異：有些需要以人命為燃料，有些會不可逆地扭曲修煉者的心智，有些觸碰了某種被默認為禁忌的領域。但「禁」不代表「不存在」。 |
| **遺跡功法** | 從大災變時代的遺跡中發掘出的功法。極其稀少，往往殘缺不全，但凡是完整的遺跡功法，品質都遠超當代任何宗門正典。問題是——幾乎沒有人能完整修煉，因為那些功法的底層邏輯與當代修仙體系有微妙的差異。 |

**按屬性/方向分：**

| 方向 | 說明 |
|------|------|
| **剛系** | 靈氣外放為主，追求破壞力。大開大合，消耗大但威力驚人。劍修、刀修中最常見。 |
| **柔系** | 靈氣內斂為主，追求控制力和持久力。看起來不起眼，但在持久戰中越打越強。棍修、軟兵器修者常走此道。 |
| **身體強化系** | 靈氣全部灌注於肉身。體修的專屬方向。不追求靈氣外放，而是把自己的身體煉成最強的武器和最硬的鎧甲。 |
| **神識系** | 強化精神力和感知力。幻術、精神攻擊、遠程感知、傀儡操控都屬於這個方向。修煉者本人戰鬥力可能不強，但一旦被他鎖定了神識，你的每一個動作都在他眼裡。 |
| **符籙系** | 將靈氣以特定紋路「刻印」在介質上，形成可儲存、可觸發的一次性靈氣構造。符師是一個獨立且極有價值的修煉方向——他們製造的符籙可以賣給凡人軍隊，讓沒有靈根的士兵也能使用一次性的靈氣爆發。 |
| **煉丹/煉藥系** | 提煉靈氣植物和礦石中的能量，製成丹藥。丹師在任何要塞都是最受尊敬的存在之一——因為丹藥可以治傷、可以輔助修煉、可以在關鍵時刻爆發超越自身境界的力量。 |
| **鍛造系** | 打造靈鍛以上品級的武器和裝備。鍛造師需要同時理解金屬、靈氣、符籙和使用者的靈氣特性。頂級鍛造師的地位不亞於戰鬥型修仙者。 |
| **陣法系** | 以多人配合或地形佈置形成靈氣共振網路。陣法師在要塞防禦中不可或缺——一座要塞的護城大陣，就是陣法師的傑作。單打獨鬥弱，但在防禦戰和團體戰中是核心中的核心。 |

### 功法的「相剋」與「互補」

功法之間不是簡單的「你克我、我克你」，而是更微妙的關係：

- 同屬性的功法對決，比的是功法品質和修為深度
- 剛系怕柔系的纏鬥拖延，但柔系也怕剛系的一擊爆發
- 神識系可以壓制大多數近戰系，但遇到體修就頭痛——體修的身體強化包含了對精神攻擊的天然抗性
- 符籙系的弱點是準備時間和符籙數量，但一個準備充分的符師比同境界的任何人都難打
- **沒有無敵的功法，只有把功法用到極致的人**

## 三、職業系統：缺一不可的生存鏈

你提到了魔力寶貝的設計哲學——出城可以，走不遠，少了誰都會死。這正是要塞文明的核心邏輯：**人類的生存從來不是靠個體的強大，而是靠分工協作。**

### 戰鬥職業

| 職業 | 角色 | 不可替代性 |
|------|------|------------|
| **劍修/刀修/各系兵器修** | 正面戰鬥主力 | 殺傷力的核心。沒有他們，隊伍沒有攻擊能力。 |
| **體修** | 肉盾/突擊 | 在獸潮中衝在最前面。別人扛不住的衝擊他扛得住。但體修消耗大，恢復慢，極度依賴後方支援。 |
| **弓修/遠程** | 防空/狙擊 | 對付飛行異獸的唯一可靠手段。在城牆防禦戰中是第一優先級。 |
| **符師（戰鬥型）** | 火力支援/陷阱佈置 | 出城前準備好的符籙就是「彈藥」。用完了就是廢人。但在決定性的一輪齊射中，十個符師的效果比三十個劍修更猛。 |
| **陣法師** | 防禦/增幅/封鎖 | 小隊作戰中負責佈置臨時陣法——增強隊友的靈氣恢復、削弱敵人的行動能力、封鎖撤退路線。單獨行動幾乎必死，但有了他的隊伍能把戰鬥力翻倍。 |
| **神識修** | 偵察/預警/精神壓制 | 能在數里之外感知異獸群的動向。在野外行動中，他是隊伍的「眼睛」。沒有神識修的隊伍等於瞎著出城。 |

### 後勤職業（同等重要）

| 職業 | 角色 | 不可替代性 |
|------|------|------------|
| **丹師/藥師** | 治療/恢復/強化 | 戰鬥中的治療丹藥、恢復靈力的藥劑、解毒丹——少了這些，一場中等規模的戰鬥之後整支隊伍就要報廢。丹師在城裡的地位極高，因為他們的產品永遠供不應求。 |
| **料理師** | 野外續航的關鍵 | 這不是開玩笑。野外的食物來源是異獸肉和靈氣植物——前者大多有毒或帶殘餘靈氣紊亂，後者不經處理直接吃可能適得其反。料理師知道怎麼處理這些食材：去毒、保留靈氣營養、甚至把特定食材搭配出臨時的「增幅效果」（不如丹藥穩定，但勝在材料易得、可批量製作）。**在城裡，料理師可能只是開館子的；出了城，他是決定隊伍能走多遠的人。** |
| **鍛造師** | 裝備維護/修理/升級 | 靈鍛級以上的武器在持續戰鬥後會出現靈氣紊亂——就像機械過熱一樣。鍛造師可以在野外進行簡單的修復。如果隊伍中沒有鍛造師，長途遠征到一半武器報廢了，那跟送死沒區別。 |
| **符師（生產型）** | 符籙製作/補給 | 跟戰鬥型符師是同一條修煉路線，但專精於製作而非使用。他們造出來的符籙賣給軍隊和其他修仙者。一個要塞的符籙庫存量直接決定了它能扛住幾波獸潮。 |
| **採集者/獵人** | 材料來源 | 深入野外採集靈藥、靈石、異獸材料。他們不一定戰鬥力最強，但他們知道哪裡有什麼、怎麼避開危險、怎麼在最短時間內拿到東西然後活著回來。很多採集者是散修——因為宗門弟子不屑於做這種「下等活」，但沒有他們，丹師拿什麼煉丹？鍛造師拿什麼鍛武器？ |
| **馴獸師** | 坐騎/偵察獸/戰鬥獸管理 | 馴服和訓練異獸為人類所用。極度危險的職業。詳見坐騎系統。 |

### 凡人職業

**沒有靈根的凡人不是廢物。** 要塞的正常運轉完全依賴凡人：

- **農人/牧人** ── 在要塞內部和近郊安全區種植靈氣穀物、飼養溫和異獸。他們是食物的源頭。
- **匠人** ── 凡鐵級武器和日常用品的製作者。不是每個士兵都配得起靈鍛武器的。
- **醫者** ── 凡人的醫術跟丹師體系不同。丹師治的是靈氣相關的傷病，醫者治的是骨折、外傷、瘟疫、難產。兩者互補，缺一不可。**主角的醫療知識在這裡有巨大的價值——他帶來的是兩千年前的醫學邏輯，有些東西這個世界的醫者從未想過。**
- **商人** ── 連接要塞內部各行業的血脈。也負責要塞之間的貿易——這需要僱傭修仙者和軍隊護送，成本極高，但利潤也極高。
- **學者/書記** ── 紀錄歷史、研究靈氣理論（不能親自修煉，但可以做理論研究）、管理文獻。要塞的行政運作離不開他們。
- **情報販子/掮客** ── 在所有勢力的夾縫中生存的人。他們賣消息、牽線搭橋、幫人辦「不方便自己出面」的事。在暗處，他們可能比明面上的權力者更清楚這座要塞到底在發生什麼。

### 職業之間的依賴鏈

出城遠征的標準配置（以一個十人小隊為例）：

> 劍修或刀修 ×2（正面戰力）
> 弓修 ×1（防空）
> 體修 ×1（抗壓）
> 符師 ×1（火力補充）
> 神識修 ×1（偵察預警）
> 丹師/藥師 ×1（醫療恢復）
> 料理師或採集者 ×1（續航保障）
> 凡人士兵 ×2（輔助戰力/搬運/雜務）

少了任何一環，出城可以，但走不遠，很容易就死。

**料理師單獨出城打怪？可以，但不強。他的最大價值是在城裡蒐羅材料、研究新配方、賣成品給遠征隊。但如果遠征隊不帶料理師，三天之後他們吃的異獸肉可能讓全隊靈氣紊亂——那跟中毒沒什麼區別。**

## 四、陣營與勢力

### 正道宗門

「正道」不代表「好人」，而是代表**認同一套共同規則的修仙勢力**。

**主要特徵：**
- 不使用禁功
- 不以凡人為修煉材料
- 承認要塞秩序，配合防禦獸潮
- 宗門之間有競爭但有底線——不在獸潮期間內鬥，不屠殺對方的凡人附庸

**正道內部的分歧：**
- 有的宗門真心認為修仙者有義務保護凡人（理想派）
- 有的宗門只是覺得維持秩序對自己有利（務實派）
- 有的宗門表面正道，暗地裡在做邊緣地帶的事（灰色派）
- 宗門之間的資源爭奪、弟子衝突、領地糾紛從未停止

### 邪道

「邪道」不代表「壞人」，而是代表**不認同正道規則、走自己路的修仙者**。

**主要特徵：**
- 修煉被正道禁止的功法（但「禁」的標準本身就有爭議）
- 不服從任何宗門或要塞的權力結構
- 很多邪修其實只是散修——他們沒有加入正道的資格或意願，被迫自己摸索修煉之路，然後因為功法來路不正被扣上「邪修」的帽子

**邪道的複雜性：**
- 有些邪修確實泯滅人性，拿活人煉丹、以殺人采補修煉
- 有些邪修只是不願意跪著修煉——他們的功法可能確實危險，但他們自己承擔風險，並沒有傷害別人
- 有些邪修組成了自己的勢力，建立了自己的小型要塞或據點——在那裡，他們就是「正道」
- **正邪之分，很多時候只是贏的人寫的歷史**

### 魔教

真正讓正道和邪道都忌憚的存在。

「魔」不是一個道德判斷，而是一個修煉方向的描述。**魔修的功法核心是：以情緒、慾望、執念為靈氣運轉的驅動力。** 正道功法要求「靜心」「無妄」「精純」，魔道功法反其道而行——你越憤怒越強、越恐懼越快、越執著越深。

**這有一個巨大的優勢和一個巨大的代價：**
- 優勢：魔修的修煉速度和戰鬥爆發力遠超同級正道修士
- 代價：長期被自身的極端情緒驅動，心智扭曲幾乎不可逆。最終大多數魔修會「入魔」——完全失去理性，變成一架只知道殺戮的戰鬥機器

**魔教不是一個統一組織，而是一個鬆散的聯盟。** 教內派系林立，頭目之間互相提防。唯一讓他們聚在一起的是正道宗門的圍剿壓力。

**最讓人不安的是：** 魔教中偶爾會出現一種人——他走魔道，承受了極端情緒的腐蝕，但他的理性始終沒有崩潰。這種人是魔教中最可怕的存在，也是正道最忌憚的對象。因為他意味著：**魔道這條路，也許不是死路。**

> 主角的性格設定在這裡有一個隱藏的呼應：他平常冷靜到冷漠，但一旦觸碰底線就會進入不死不休的暴力狀態。這種「極端情緒爆發但平時理性完整」的特質，跟魔修的路徑有一種微妙的相似性——但他不是魔修，他只是一個人。這種相似性可能在未來引發一些有趣的劇情張力。

### 隱世勢力

不屬於正邪魔任何陣營，但確實存在的力量：

- **古修士/隱居者** ── 修煉到極高境界後選擇避世。他們不參與人間紛爭，但如果有人觸碰了他們的禁忌……
- **遊商聯盟** ── 穿梭於各要塞之間的商人組織。表面中立，但情報網絡驚人。在正邪衝突中扮演微妙的調停者角色。
- **遺跡探索者** ── 專門進入大災變遺跡尋寶的團體。九死一生，但一旦找到真正的遺跡功法或上古武器，足以改變一個宗門的命運。
- **「守墓人」** ── 一個極度神秘的組織。他們似乎在守護某些東西——某些與大災變真相有關的東西。他們不站任何一邊，但偶爾會以不可理解的方式介入某些事件。**沒有人知道他們到底在守什麼。**

## 五、政治系統

### 要塞級政治

每座要塞都是一個獨立的政治實體。沒有統一的「帝國」或「王朝」——因為要塞之間的距離太遠、野外太危險，不可能形成穩定的大一統政權。

**常見的要塞政體：**

| 類型 | 說明 | 例 |
|------|------|----|
| **宗門主導** | 一個大宗門建立的要塞，宗門掌門就是要塞之主。凡人和軍隊服從宗門的管理。秩序穩定但階級分明。 | 「正道大派的山門要塞」 |
| **世家聯治** | 數個修仙世家共同管理。表面是議會制，實際是家族利益博弈場。效率低但不容易出暴君。 | 「繁華的貿易型要塞」 |
| **軍政體制** | 軍隊掌權。通常出現在邊陲要塞——因為那裡獸潮頻繁，軍事效率比政治正確更重要。修仙者在軍中服役，凡人也有更多上升通道。 | 「前線堡壘型要塞」 |
| **鐵腕統治** | 一個極其強大的個人掌控一切。可能是暴君，也可能是鐵血但公正的守護者——外人無法輕易判斷。 | 「某個歸真境強者的領地」 |
| **混亂邊城** | 沒有穩定政權，各方勢力拉鋸。危險但自由。走私犯、散修、逃犯、冒險者聚集。 | 「三不管地帶的小型要塞」 |

### 要塞間政治

- **貿易同盟** ── 數座要塞結成貿易夥伴關係，共享商路護衛費用。
- **宗門勢力範圍** ── 大宗門往往控制數座要塞，形成事實上的「領地」。
- **戰略聯防** ── 相鄰要塞在大規模獸潮或魔教進攻時互相支援。但能不能真的指望盟友，每個要塞主心裡都有數。
- **暗戰** ── 要塞之間爭奪靈石礦脈、靈藥產地、戰略通道的暗鬥從未停止。有時候這些暗戰的殘酷程度不亞於獸潮。

## 六、經濟系統

### 貨幣：多軌並行

這個世界沒有統一貨幣。不同的圈子用不同的東西交易。

| 貨幣/等價物 | 流通圈 | 說明 |
|-------------|--------|------|
| **銅/銀/金幣** | 凡人之間 | 要塞內部鑄造的金屬貨幣。買菜、吃飯、租房、僱工——凡人日常生活的交易媒介。不同要塞鑄造的貨幣之間有匯率差。 |
| **靈石** | 修仙者之間 | 天然的靈氣結晶體，可以直接吸收靈氣修煉，也可以作為各種靈氣設備的「燃料」。是修仙者之間最通用的硬通貨。分低階靈石、中階靈石、高階靈石，價值以百倍遞增。 |
| **強化石（淬靈石）** | 鍛造/裝備圈 | 一種特殊礦石，可以提升靈鍛級以上武器和裝備的品質。好的強化石比靈石更稀缺。鍛造師和追求頂級裝備的修仙者會直接用強化石交易，不過手靈石。 |
| **丹藥/符籙** | 實物交易 | 在靈石不夠用的時候，直接以丹藥或符籙易物。尤其在邊陲小要塞，一瓶治療丹比一百塊靈石更有用。 |
| **情報/人情** | 暗市 | 在情報販子和掮客的圈子裡，消息本身就是貨幣。一條準確的礦脈情報可以換到一支遠征隊的護送。 |
| **軍功點** | 軍方體系 | 要塞軍隊內部的積分制。殺異獸、守城、完成任務都能積累軍功點。軍功點可以在軍方商行兌換武器、丹藥、修煉資源，甚至宅地分配和家屬庇護資格。 |

### 經濟的運作邏輯

- **城內經濟**：凡人用金屬貨幣，修仙者用靈石。兩個經濟圈有交集——凡人的手工藝品、食材、服務（包括料理師的料理）可以賣給修仙者換取少量靈石或靈石的碎片。
- **城際貿易**：風險極高、利潤極高。需要僱傭修仙者和軍隊護送的商隊。專業的遊商聯盟壟斷了大部分城際貿易。
- **黑市**：每座要塞都有黑市。禁功、禁藥、違禁材料、走私的軍方物資——什麼都能買到，但價格和風險都翻倍。
- **壟斷問題**：大宗門和世家壟斷了靈石礦脈和靈藥產地，散修和小勢力只能買高價的二手資源。這是正邪衝突的經濟根源之一。

## 七、道具與寶具系統

### 分類框架

這個世界的物品不按「武器/防具/道具」這種遊戲式分類，而是按**靈氣含量和功能**分：

| 類別 | 定義 | 舉例 |
|------|------|------|
| **凡物** | 不含靈氣的普通物品 | 凡鐵武器、普通衣物、日常用品 |
| **靈物** | 含有靈氣但功能單一、被動的物品 | 靈石、未加工的靈性礦石、靈氣植物 |
| **法器** | 經過人工鍛造/煉製，被賦予特定功能的靈氣物品 | 靈鍛武器、防護甲胄、儲物袋、通訊玉簡、照明靈燈、淨水靈壺 |
| **寶具** | 法器的上位。更強的靈氣構造，更複雜的功能，甚至可能有簡單的自主反應能力 | 道器級武器、自動防禦型護甲、飛行法器、大範圍探測器、困敵結界盤 |
| **秘寶** | 寶具的上位。獨一無二的存在，通常有自己的「脾氣」 | 靈寶級武器、傳承級護甲、空間型儲物寶器、天象級法陣核心 |
| **禁物** | 不分等級，只要被認定為「不應存在」或「不應被使用」的物品 | 魔道祭器、某些遺跡中挖出的不明物體、功能已失控的上古秘寶 |

### 常見法器與寶具

**日用型：**
- **儲物袋/儲物戒** ── 內部有壓縮空間的容器。越高級空間越大。頂級的儲物秘寶甚至可以裝下一座小山丘的物資。
- **通訊玉簡** ── 類似對講機。靈氣驅動，有效距離取決於品質。要塞間的長距離通訊需要中繼站。
- **靈燈** ── 靈氣驅動的光源。在野外夜間行動中不可或缺——因為火光會吸引異獸，但靈燈的光不會。
- **淨水/淨食器** ── 可以淨化水源和食物中的靈氣紊亂。料理師的必備工具。
- **身份令牌** ── 要塞發放的身份憑證。記錄持有者的身份、修為等級、職業、所屬勢力。進出城門必查。

**戰鬥型：**
- **護身符/護甲** ── 被動防禦型法器。品質決定能擋幾次攻擊。消耗品性質——擋完就碎。好的護身符在黑市上價格驚人。
- **困敵型法器（結界盤、封印符、禁錮鎖）** ── 不殺敵，而是限制敵人的行動。陣法師的延伸裝備。
- **飛行法器** ── 用靈氣驅動的飛行載具。從簡單的飛盤到複雜的飛舟都有。但在高空飛行極度危險——因為天上有飛行異獸和龍種。通常只用於短距離快速移動或緊急撤退。
- **斗篷/遮蔽衣** ── 特殊法器，可以遮蔽使用者的氣息。在異獸橫行的野外，一件好的遮蔽斗篷可能救命。但對高等級的異獸和修仙者無效。

### 武器是法器的一種

在這個分類裡，靈鍛以上的武器本身就是法器。道器級以上的武器就是寶具。靈寶級以上是秘寶。所以武器和道具不是兩個系統——**武器是道具系統中「功能為戰鬥」的那個分支。**

斗篷也一樣。一件普通斗篷是凡物。一件能遮蔽氣息的斗篷是法器。一件能主動吸收攻擊能量的斗篷是寶具。一件能讓穿戴者在攻擊命中的瞬間瞬移到三丈外的斗篷——那是秘寶級的存在，可能整個世界只有幾件。

## 八、坐騎系統

### 坐騎的來源

坐騎是被馴化的異獸。不是所有異獸都能成為坐騎——需要滿足三個條件：

1. **體型和結構適合承載人類**
2. **智慧程度足夠理解指令**（太笨的馴不了，太聰明的不願意被馴）
3. **靈氣屬性與騎手兼容**（不兼容的話，長期接觸會讓騎手和坐騎都靈氣紊亂）

### 坐騎分級

| 等級 | 說明 |
|------|------|
| **馱獸** | 最低級。只能負重行走，不能飛行，戰鬥力幾乎沒有。凡人商隊的牲口。 |
| **戰騎** | 可以在地面快速移動，有一定戰鬥力。軍隊的騎兵部隊坐騎。 |
| **靈騎** | 與騎手形成靈氣共鳴的坐騎。速度、耐力、戰鬥力遠超戰騎。修仙者才能馭使。 |
| **飛騎** | 可以飛行的靈騎。數量稀少，每一頭都是戰略資源。擁有飛騎的修仙者在空戰中有碾壓性優勢。 |
| **靈獸** | 不是「坐騎」，而是「夥伴」。智慧極高，有自己的情感和判斷力。與主人的關係不是馴服，而是信任。非常罕見。 |

### 馴獸師

馴獸是一門獨立的修煉方向。馴獸師需要：
- 極強的神識（用精神力與異獸溝通）
- 對異獸習性的深入了解
- 足夠的膽量和耐心

馴獸師的社會地位很微妙——正經的馴獸師受人尊敬，但很多馴獸師在馴服過程中受重傷甚至死亡，所以這行業的淘汰率極高。

### 愛醬的可能性

**愛醬不是這個世界的異獸。** 牠沒有靈氣基因，牠的體型是一隻大型犬，不是一頭巨獸。讓牠變成戰鬥坐騎在目前的設定邏輯下是不合理的。

**但——**

愛醬是這個世界上唯一沒有被靈氣影響的「純淨」生物。牠的身體長期跟靈氣環境接觸，可能會發生一些緩慢的、不可預見的變化：

- **體型可能緩慢增大**——不是變成巨獸，但也許從一隻大型犬慢慢長成一頭……更大的犬？大到足以在某些緊急情況下馱主人跑一段路？
- **牠的「純淨」本身可能產生特殊效果**——比如在靈氣極度紊亂的區域，牠身上散發的「空白」反而成為一個小型的穩定錨點。主角站在牠旁邊修煉可能更穩定。
- **牠的觀察力會持續進化**——不是開天眼，而是一隻已經極聰明的狗在靈氣環境中被微弱增幅後，對情緒、敵意、危險的感知達到了超自然的精準度。

**到了故事很後面——也許某一天——愛醬可以成為某種意義上的「坐騎」。** 不是因為牠變成了靈獸，而是因為在漫長的歲月裡，牠和主角之間的羈絆本身成為了一種力量。牠願意馱著他，他信任牠的判斷。在那一刻，所有見證者會看到一個修仙者騎在一隻……誰也說不清到底是什麼的大型犬類身上，而那隻「狗」的眼神比很多靈獸都更清澈、更堅定。

**那個畫面本身就會成為這部作品的標誌性場景。**

## 九、主角的武器之路（補充）

結合以上所有系統，主
