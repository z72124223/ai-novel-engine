# Chenxing Visual Bible Inventory

本目錄是 WP-003 的證據盤點，不是圖片交接包、視覺批准、Canon（正典）、正式媒體或 production lock（生產鎖定）。

- `chenxing_visual_asset_inventory_v1.json`：角色、動物、服裝、風格與道具證據。
- `chenxing_location_bible_gap_inventory_v1.json`：大坪海岸、撤退路線與遺跡室內的場景幾何缺口。
- `opening_shots_01_03_readiness_v1.json`：首三鏡引用、上傳需求與 WP-004 disposition（處置判定）。

檔案存在、SHA-256 與尺寸只證明檔案可識別。視覺權威來自引用的正式文件；Repository（程式庫）路徑不表示圖片已附加至 ChatGPT 對話。
