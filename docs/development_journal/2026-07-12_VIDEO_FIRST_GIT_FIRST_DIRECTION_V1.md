# 2026-07-12 — 影片優先與 Git 優先方向紀錄 V1

Status: `ACTIVE_PROJECT_MEMORY`

## 1. 使用者指出的偏移

使用者在閱讀 STORY-01〈潮線之外〉後，指出三個重要問題：

1. 不應為了製造衝突，強迫主角犯低級錯誤或變笨；
2. 對話仍有「兩個 AI 在互相講完整論點」的感覺，不像真人，也不像華人自然說話；
3. 專案最終目標是影片，但新窗口經常因看到小說樣本，就把專案重新理解成小說生成器。

使用者另外明確要求：

> GitHub 應該是多人團隊最重要的協作、交接、版本與長期記憶場所，而不是某一台主機環境。

## 2. 主角方向修正

取消「主角必須犯一次錯才有成長」這種要求。

陸塵行可以長期保持：

- 聰明；
- 可靠；
- 有觀察力；
- 會辨認明顯危險；
- 不因劇情需要突然失去常識。

他的主要成長線放在進入新世界之後：

- 適應不同文化；
- 理解新世界制度與人情；
- 理解力量、階級和權力；
- 學會承擔更多人的生命與選擇；
- 從解決自己與愛醬的問題，成長到能影響戰局與世界。

戲劇衝突不依靠降智，而依靠：

- 資訊不足；
- 正確決定也有代價；
- 兩種價值不能同時保全；
- 對手會學習；
- 地球常識無法完整套用新世界；
- 力量越大，責任與政治後果越大。

## 3. 對話方向修正

STORY-01 已比早期樣本自然，但仍有：

- 句子太完整；
- 每個人都太會說；
- 太多可以單獨截圖的句子；
- 太多工整的否定轉折；
- 角色缺少打斷、停頓、逃避與誤解；
- 不同角色的說話節奏仍可再拉開。

新的正式要求：

```text
繁體中文母稿
＋自然台灣華語角色聲音
＋泛華語市場可理解
```

目標讀者包含：

- 台灣；
- 中國大陸；
- 香港；
- 馬來西亞；
- 新加坡；
- 其他華語地區。

不把所有語言洗成無地區特色的書面中文；母稿保持台灣角色自然口氣，發行時另做地區在地化。

## 4. 最終產品方向修正

正式寫死：

> **主要終點是影片／動畫，不是小說。**

正確主線：

```text
世界觀與角色
→ 故事事件主檔
→ 影視劇本
→ 場景與正式對白
→ 分鏡與鏡頭表
→ 固定角色／場景資產
→ 關鍵影格
→ 單鏡影片
→ 剪輯、聲音、字幕
→ 完整影片
```

小說版可以保留作為：

- 故事品質測試；
- 補充出版物；
- 內心描寫版本；
- 影視劇本的來源之一。

但小說不再是最高生產權威。

## 5. GitHub 協作方向

正式採用：

```text
GitHub remote = 團隊協作最高權威
本機環境 = 可替換執行環境
```

重要成果不能只留在：

- 某一台電腦；
- 終端輸出；
- 未 Push Worktree；
- `out/**`；
- 本機 SQLite；
- 私人絕對路徑。

劇本、對白、分鏡、鏡頭表、評審、作者決策、Hash、操作說明與交接包都要 Commit／Push。

每次工具交接使用：

```text
Repository
Branch
Commit SHA
Repo-relative Path
Content SHA-256
```
