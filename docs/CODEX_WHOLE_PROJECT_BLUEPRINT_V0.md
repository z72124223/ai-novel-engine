## Purpose

This is the top-level blueprint for the whole project. It prevents future
windows from treating the current renderer-manifest micro-phase chain as the
entire product plan.

The final product target is a local-first pipeline that can turn user-approved
worldbuilding, setting, scene intent, storyboard data, asset references, voice
timing, and renderer-ready packets into a reviewable voiced-comic video
deliverable. The current repository is still Kotlin/JVM CLI, SQLite, and JSON
file protocol only.

This document is planning/control only. It does not approve canon, registry,
release, production lock, final media, provider/media handoff, external paid
tools, schema changes, renderer execution, ffmpeg/TTS execution, or direct
SQLite writes.

## Data And Retrieval Blueprint

The data layer must be explicit before implementation:

- Source docs and planning registers remain non-canon until promoted.
- Query packets should request scoped facts, not whole world dumps.
- A future local hybrid path may combine exact SQL/FTS/BM25 retrieval with
  Embedding candidate recall and Reranker ordering, but only after an offline
  benchmark proves useful quality and acceptable local latency.
- Any extraction output or retrieval index remains provisional, source-linked,
  and rebuildable. Retrieval relevance never grants character knowledge,
  Canon status, write authority, or permission to expose author-only material.
- SQLite remains runtime state and approved setting-pack data only; direct SQL
  writes are forbidden.
- Any future SQL / schema / migration / query-audit table work requires its own
  explicit milestone.
- No vector DB, embedding, external retrieval, or provider/API path is approved.

Minimum future artifacts:

1. Authority/retention registry and fresh-clone rebuild manifest defined by
   `RETRIEVAL-00`.
2. Logical-content rebuild report that does not rely on SQLite binary hashes.
3. `BlueprintRecord` / planning register entry format.
4. `QueryRequest` / `QueryResponse` JSON templates.
5. `QueryScopeReviewReport` for checking no author-only leakage and no overbroad
   retrieval.
6. Mapping from 09 cards to script-ready scene packets.
