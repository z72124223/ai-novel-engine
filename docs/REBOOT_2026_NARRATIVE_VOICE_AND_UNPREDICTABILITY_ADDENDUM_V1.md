本文件是 2026 Playable Depth Reboot 的正式敘事補充。它不取代世界合法性、SQLite、Transaction、Knowledge Boundary、Canon 或正式資產批准邊界；它定義故事應讓讀者感受到什麼，以及 REBOOT-01 必須如何實測。

## 1. 讀者體驗北極星

使用者要的不是持續陰鬱、持續搞笑或只靠升級打怪的故事，而是能讓讀者真正住進角色生活中的長篇世界：

```text
先因角色而笑
→ 因日常與關係而靠近
→ 因衝突而緊張
→ 因不公與代價而憤怒
→ 因選擇而反思
→ 因失去、理解或和解而落淚
→ 得到喘息、溫暖或新的希望
→ 願意繼續陪角色生活
```

本專案可以借鑑優秀作品的高層節奏、群像成長、價值衝突與情緒起伏，但不得複製特定作品的角色、台詞、情節、標誌性場景或獨特表達。

## 2. 情緒波形，而非單一色調

每個場景不必走完全部情緒，但一個 5–10 回合垂直切片至少應包含：

1. 自然笑點；
2. 日常摩擦或人物缺點；
3. 溫暖、信任、友情、可愛或戀愛張力；
4. 不安訊號；
5. 真實衝突；
6. 非黑即白以外的價值兩難；
7. 不可逆代價；
8. 憤怒、失落或無力；
9. 一次安靜的反思；
10. 一個局部希望與新的未解問題。

情緒轉折必須由前文因果、關係與承諾累積，不得使用無準備的廉價死亡、突然背叛或任意災難假裝深度。

## 3. 陸塵行的毒舌與吐槽方向

### 3.1 目的

主角可以加入毒舌、吐槽與敏銳觀察，使他：

- 對不合理命令、顯而易見的危險與官腔保持警覺；
- 說出讀者心中會想到、但一般角色常被迫忽略的問題；
- 用幽默揭露制度荒謬、人際尷尬、敵我矛盾和自己的狼狽；
- 降低「恐怖片角色明知危險還作死」式的劇情依賴；
- 形成鮮明聲音，讓讀者期待他如何回應局勢；
- 以嘴硬、反諷或自嘲防禦恐懼、羞恥與關心。

### 3.2 不是第四牆超能力

毒舌與類型敏感不等於全知。

陸塵行可以：

- 看出門後可能有埋伏；
- 懷疑「分頭行動」很蠢；
- 發現槍械對某敵人可能無效；
- 質疑過度方便的情報；
- 提醒大家不要碰明顯異常物；
- 對看似套路化的局勢做現實推理。

但他不能：

- 知道自己身處小說或遊戲；
- 因熟悉類型片就直接知道作者秘密；
- 準確預言未見過的敵人能力；
- 用一句吐槽取消世界規則、恐懼、代價或他人的專業；
- 永遠正確。

他的判斷應來自經驗、常識、觀察、人格與已知資訊。錯誤判斷也要有合理原因。

### 3.3 吐槽節奏

禁止讓主角變成每句話都講梗的網路迷因機器。

建議節奏：

```text
日常／低壓：可以多一點自嘲、毒舌與互相吐槽
中壓：笑點變短，用來調節恐懼或建立團隊默契
高壓：只留下精準的一句，或完全沉默
重大代價後：不應立刻用笑話取消悲傷
恢復期：幽默重新出現，顯示人物仍願意活下去
```

真正沉重時主角不吐槽，反而能讓讀者感到事情嚴重。

### 3.4 吐槽必須有角色後果

毒舌不是免費能力。它可能：

- 拉近熟人關係；
- 傷害脆弱角色；
- 激怒權力人物；
- 暴露主角緊張；
- 被對手反擊；
- 在錯誤時間顯得殘酷；
- 成為後續道歉、信任或戀愛的素材。

每個重要角色對吐槽的反應應不同，不能全員只負責接梗。

## 4. 反「角色作死」原則

故事不得主要依賴角色突然變笨才前進。

當角色面對明顯危險時，至少要有一項成立：

- 他不知道關鍵資訊；
- 他有更重要的人或目標必須救；
- 時間不足；
- 退路更危險；
- 權力、責任、承諾或情緒迫使他冒險；
- 對手刻意製造錯誤訊息；
- 角色的錯誤信念使其選擇合理但錯誤；
- 角色明知風險，仍願意支付代價。

禁止：

- 只為觸發驚嚇而獨自進入危險區；
- 已證明武器無效仍無限重複同一攻擊；
- 為讓反派逃走而突然停止追擊或溝通；
- 角色忘記上一回合剛得到的資訊；
- 專業角色在自己的專業上無理由失能；
- 所有人忽略主角已提出的合理警告。

## 5. 降低可預測性的「公平意外」

### 5.1 不是隨機反轉

讀者不能一直準確預測所有劇情，但解法不是隨機改規則。好的意外應符合：

```text
先有可見線索
→ 讀者形成合理預測
→ 角色也可能察覺第一層危險
→ 第一層預測被承認或部分成功避開
→ 世界、對手或代價產生第二層合理反應
→ 結果出乎意料但回看時成立
```

這稱為 `fair_surprise`，不是 `cheap_twist`。

### 5.2 預測承認原則

如果讀者和聰明角色都能看出「門後可能有鬼／伏兵」，故事不應強迫所有人假裝看不出來。

正確做法之一：

1. 主角指出危險；
2. 團隊採取措施；
3. 第一個陷阱被避開；
4. 對手因團隊的警覺改變策略；
5. 真正的代價出現在不同但因果合理的位置。

這會讓讀者感到角色聰明，而故事仍不可完全預測。

### 5.3 可預測性控制工具

Drama Director 與 Critics 應追蹤：

```text
audiencePredictionRisk
stupidityDrivenPlotRisk
cheapTwistRisk
fairForeshadowing
secondOrderConsequence
antagonistAdaptation
promisePayoffIntegrity
genreAwareness
banterNaturalness
voiceDistinctiveness
```

每項 0–10 或明確 Finding。

### 5.4 意外來源優先級

優先使用：

- 角色目標互相碰撞；
- 對手根據主角行動學習；
- NPC 在玩家不在場時推進自己的計畫；
- 先前承諾或債務被追討；
- 資源與時間成本；
- 正確選擇仍有副作用；
- 角色掌握不同資訊；
- 同一事件對不同群體造成不同後果；
- 主角能力成長引發更大責任與政治影響。

最後才使用：

- 新敵人突然出現；
- 隱藏血統；
- 無線索背叛；
- 失憶；
- 任意死亡；
- 世界規則突然改寫。

## 6. 主角成長與戰局影響

陸塵行可以逐步成為能左右戰局、政治或文明方向的人，但成長需要多軸同步：

```text
combatCapability
knowledge
strategicJudgment
relationships
reputation
socialInfluence
leadershipBurden
moralCompromiseRisk
lossAndSacrifice
falseBeliefCorrection
```

禁止只有數值變高、敵人變大。每個新能力應同時帶來：

- 新責任；
- 新敵人或關注；
- 更難的選擇；
- 失去普通生活的風險；
- 對身邊角色關係的改變。

## 7. 群像、溫暖、戀愛與意難平

每個重要角色都需要自己的：

- 欲望；
- 恐懼；
- 錯誤信念；
- 底線；
- 玩家不在場時的計畫；
- 對主角既有依賴之外的關係；
- 成長或惡化可能；
- 能給讀者的情緒價值。

戀愛不只靠表白或誤會；應由：

- 一起承擔風險；
- 注意對方小習慣；
- 互相吐槽與保護；
- 價值觀衝突；
- 無法同時滿足的責任；
- 選擇留下、離開、等待或犧牲；

逐步形成。

「意難平」可以來自錯過、不同道路、無法挽回的選擇、時代與責任，而不必總靠死亡。

## 8. 無最終終局的正確形式

採用：

> `local_closure + persistent_world_continuation`

每卷、季、篇章或重大事件必須局部收束：

- 回收至少一個承諾；
- 完成一個角色階段；
- 改變至少一段關係；
- 留下永久世界狀態；
- 讓某個代價被承認；
- 開啟新的生活面向或問題。

世界可以一直延續，但禁止永遠拖著同一問題不解決。

## 9. REBOOT-01 強制實測條件

5–10 回合垂直切片至少要有：

1. 一次自然毒舌／吐槽，能揭露人格或關係；
2. 一次主角辨認明顯類型危險並採取合理措施；
3. 第一層明顯危險被避開或降低；
4. 一次由對手、世界或代價產生的第二層合理意外；
5. 一個笑點在後續得到關係或因果回收；
6. 一次高壓時主角不靠笑話逃避；
7. 一次溫暖或戀愛／親密張力；
8. 一次價值兩難；
9. 一次不可逆但 non-canon Runtime 後果；
10. 一次 NPC 玩家離場行動；
11. 一個局部收束；
12. 一個讓讀者想繼續追的未解問題。

Critics 必須分別評估：

```text
sarcasmVoiceFit
banterNaturalness
genreAwarenessWithoutOmniscience
stupidityDrivenPlotRisk
audiencePredictionRisk
fairSurprise
cheapTwistRisk
emotionalWaveCoverage
relationshipPayoff
readerAttachment
```

低分是 Evidence，不應自動阻止保存。每回合最多修訂一次。

## 10. 防止 AI 作文感

Writer 應避免：

- 每段都總結情緒；
- 反覆解釋剛發生的事；
- 所有人說話同一語氣；
- 把設定講成百科；
- 用抽象形容詞代替具體行動；
- 每個角色輪流講完整論點；
- 每段結尾都製造假懸念；
- 對話沒有打斷、誤解、沉默、轉移或潛台詞；
- 毫無狀態改變的長對話。

優先：

- 具體動作；
- 不完整但有角色特色的話；
- 不同角色不同節奏；
- 留白；
- 情緒通過選擇與身體表現；
- 場景結束時發生狀態、關係、價值、代價或資訊變化。

## 11. 版本與演化

本憲章不是一次寫死的風格命令。REBOOT-01 需保存：

- raw draft；
- critic scores；
- revision suggestion；
- revised draft；
- reader-facing result；
- Rule Set version；
- same-seed replay comparison。

只有同 Seed 對比顯示更好，才把新規則升級。不得因單次主觀高分就永久改寫全專案。

## 12. 邊界

本文件不授權：

- 修改正式 Canon 角色命運；
- 複製特定作品；
- 讓 Drama Director 控制角色意志；
- 讓 Critic 直接改 SQL；
- 無限修訂；
- 用隨機反轉代替因果；
- 以毒舌取消創傷、悲傷、愛或責任；
- 將測試中的主角新聲音直接宣稱為 AUTHOR_LOCKED Canon。

陸塵行的毒舌／吐槽方向先在 REBOOT-01 non-canon 垂直切片實測；驗證讀者吸引力與角色一致性後，再由使用者決定是否升格到正式角色資料。
